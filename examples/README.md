## Sample OpenAPI documents

Each pair below shows a plain OpenAPI 3.0 document (`*-basic.json`) and an extended version (`*-extended.json`) with generated `x-mcp` name, description, and inline `inputSchema`/`outputSchema` metadata for every operation.

- `openapi-todo-basic.json` → `openapi-todo-extended.json`
- `openapi-users-basic.json` → `openapi-users-extended.json`
